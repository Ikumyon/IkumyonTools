# Ikumyon Tools Docs

Ikumyon Tools のドキュメントおよびポータルサイトです。

日本語・英語に対応しています。翻訳は画面コードから独立したファイルで管理し、詳細説明は固定IDのブロックごとに訳文をかぶせます。

翻訳ファイルの場所と更新手順は [翻訳ガイド](docs/translations.md) を参照してください。

## ツールの追加と自動計測

`tools/<ツールID>/tool.json` と既存形式の翻訳・説明・画像を追加すると、ビルド時に一覧へ自動登録されます。IDは英数字から始まる英数字・ハイフン・アンダースコアの1〜80文字です。日本語名は `locales/ja.json` の `name` が必須です。

同じ検出処理で `tools-catalog.json` を公開します。形式は `{ version: 1, tools: [{ id, name }] }` です。開発サーバーでも同じURLを利用できます。解析側の次回取得時にアクセス0件でも登録され、通常は最大5分程度で反映されます。解析側の再デプロイは不要です。

トップ・ツール詳細の表示とダウンロードボタン操作は共通処理で計測します。計測先との通信失敗はサイト操作を妨げません。

## 開発環境のセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# プレビュー
npm run preview
```

`npm run build` は翻訳チェックと型チェックを実行し、画像・ツール設定・日英の詳細説明を含めたサイトを `dist/` に出力します。

```bash
# 翻訳の不足・原文の未確認変更・変数・参照先を検査
npm run check:translations

# 言語判定・詳細説明の対応付け・翻訳チェックのテスト
npm test
```
