## Overview

**Paratranz Mod Checker** is a desktop tool for managing source updates in translation mods. Compare local source files with Paratranz and apply changes to Paratranz.

<!-- i18n:features -->
## Features

- Detect changes in local source files and sync them to Paratranz.
- Register and manage multiple Paratranz projects.
- Filter projects by game.
- Check for updates in the background with system tray notifications.
- Configure a source folder and include/exclude patterns for each project.
- Choose the interface language in settings. Restart the app to apply changes.

<!-- i18n:installation -->
## Getting started

Extract the package for Windows or Linux. On Windows, launch `Paratranz Mod Checker.exe`; on Linux, launch `Paratranz Mod Checker`. Keep the bundled folders alongside the executable. A separate Python installation is not required.

<!-- i18n:usage -->
## Usage

1. Set the Paratranz API URL and Personal Access Token in settings.
2. Enter a Paratranz project URL or ID in the add project screen and fetch its information.
3. Select the local source folder, configure include/exclude patterns if needed, and register the project.
4. Run an update check, review the detected differences, and sync them to Paratranz. Write access to the target project is required.
5. Enable automatic checks in settings to keep monitoring for updates.
