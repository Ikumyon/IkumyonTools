## About AUTOlingua Desktop

**AUTOlingua Desktop** is a desktop app for translating and editing game and mod localization files.
Use one project for AI translation and review, glossary and tone settings, source updates and translation export.

It supports Paradox YAML and ParaTranz JSON. Plugins extend AI connections and file formats.

<!-- i18n:features -->
## Features

- **AI translation and review**: Translate text, review translations with AI, and compare results from multiple models before choosing one.
- **Glossaries and tone**: Keep names and terminology consistent, with general and conditional tone settings.
- **Source updates**: Detect changes in source folders, review additions, changes and deletions, and import updates while carrying translations forward.
- **Multiple target languages**: Add translation languages to the same source and manage text and progress for each language.
- **Export**: Export Paradox YAML, ParaTranz JSON and character lists for BMFont.
- **AI chat and automation**: Work through chat or connect tasks using scripts, triggers and MCP.

## Download and launch

Choose the package for your operating system in this page’s download section.

1. Download the ZIP for Windows or tar.gz for Linux and extract the entire folder.
2. Run `AUTOlingua2.exe` on Windows or `AUTOlingua2` on Linux. If Linux requires execute permission, run `chmod +x AUTOlingua2`.
3. Keep the launcher and bundled `core` folder in their original layout. Do not move the executable alone.
4. Choose the display language and AI connection and model during setup, then test the connection.
5. Create a project, add source files and a target language, and start translating.

**Distribution in preparation**: Download filenames are placeholders: `AUTOlingua2-windows.zip` for Windows and `AUTOlingua2-linux.tar.gz` for Linux. Downloads become available when matching assets are attached to a release.

<!-- i18n:ai -->
## Using AI

Depending on the connection, AI features require an API key or authentication.
AI usage follows the connected service’s terms and pricing. Connection plugins include OpenAI, Gemini and Claude.

Import source files, select the target language, translate, edit or review, then export. Set glossaries and tone before translating to include them in the instructions.
