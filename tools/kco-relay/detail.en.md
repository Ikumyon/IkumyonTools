## Overview

**KCO Relay** is a desktop companion that receives and relays currently playing titles from tools such as KCO title fetcher on your local machine.
Together with Kancolle Stream Overlay, it displays BGM titles on your stream in real time.

<!-- i18n:features -->
## Features

Receives title information from browser extensions and forwards it to the BGM display in Kancolle Stream Overlay.
This lightweight companion runs on Windows / Linux. Prebuilt packages are available from GitHub Releases.

<!-- i18n:downloads -->
## Downloads

The latest version is distributed as assets on GitHub Releases.

- Windows: Extract `kco-relay-windows-x86_64.zip` and launch `kco-relay.exe`.
- Linux: Extract `kco-relay-linux-x86_64.tar.gz` and launch `./kco-relay`.

The Linux version is built on Ubuntu 22.04 for x86_64. It requires a graphical desktop and shared libraries including D-Bus, Fontconfig and XKB.

<!-- i18n:related -->
## Related tools

- **KCO title fetcher**: Retrieves and sends currently playing titles from YouTube / Niconico.
- **Kancolle Stream Overlay**: Displays the received BGM titles on your stream.
