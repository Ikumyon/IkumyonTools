# 翻訳の管理

画面構造と配布設定を共通にし、日本語を原文として選択言語の文章をかぶせて表示します。翻訳ファイルはビルド時に検査されます。英語を公開するには、共通UIと全ツールの翻訳をそろえる必要があります。

## 編集するファイル

| 内容 | 日本語（原文） | 英語 |
| --- | --- | --- |
| ボタン・見出し・エラー・読み上げ文言 | `src/i18n/locales/ja.json` | `src/i18n/locales/en.json` |
| ツール名・概要 | `tools/<id>/locales/ja.json` | `tools/<id>/locales/en.json` |
| 詳細説明 | `tools/<id>/detail.md` | `tools/<id>/detail.en.md` |

通常の翻訳では TypeScript、HTML、`tool.json` を編集する必要はありません。`tool.json` は GitHub、配布ファイル、画像などの言語に依存しない情報を保持します。

## ツール本体の対応言語

一覧と詳細の「対応言語」は、ツール本体の表示言語を表します。サイトの説明が英訳されていることとは別の情報です。表示部品は `src/components/tool-languages.ts` に共通化しています。

各ツールの `tool.json` の `supportedLanguages` だけで設定します。例えばツール本体が日本語・英語に対応していると確認できた場合は、次のように指定します。

```json
"supportedLanguages": ["ja", "en"]
```

空配列 `[]` または省略時は「未確認 / Not confirmed」を表示します。AUTOlingua Desktopは翻訳フォルダーの登録情報に基づく42言語・地域、その他のツールは日本語のみ（`["ja"]`）に設定しています。確認できた言語だけを登録してください。

言語名はその言語自身の表記に固定します。サイトを英語表示にしても、日本語は「日本語」、英語は「English」と表示します。欄名や区切りはサイトの表示言語に合わせます。`fr`、`zh-Hant` など、サイト自体の対応言語以外も指定できます。言語タグの誤りや大文字・小文字だけが異なる重複は翻訳チェックで検出します。

一覧・詳細とも、サイトの表示言語に対応する言語を先頭に表示します。例えば英語表示では `en-US` の「English」、日本語表示では `ja-JP` の「日本語」が先頭になります。同じ言語の地域別コードも優先対象とし、それ以外は `supportedLanguages` の登録順を維持します。表示言語がツールの対応言語に含まれなければ、登録順のまま表示します。

件数は「42言語対応 / 42 languages supported」のように表示します。地域別コードも1件として数えます。5件以上、または言語名の一覧が80文字を超える場合は、初期状態を折りたたみ、先頭3件をプレビュー表示します。件数をクリックすると全件を開閉できます。日本語のみの場合は「1言語対応 · 日本語」と表示します。

AUTOlinguaの各 `translations/<言語>/metadata.json` の `code` と `name` を、共通の `src/i18n/language-names.mjs` に登録しています。登録済みの現地語名を優先し、未登録の言語はブラウザの言語名データから自言語表記を取得します。フォルダー名が `ja_JP` でも、サイトにはメタデータの正規コード `ja-JP` を使います。翻訳フォルダーへの参照はビルド時・実行時には必要ありません。

## 共通UIの翻訳

同じIDの値を書き換えます。IDは文章を変更しても維持します。

```json
{
  "common.download": "Download",
  "release.reset": "Resets at {time} (about {minutes} minutes remaining)"
}
```

- 一文を途中で分割せず、訳文側で語順を変えられるようにします。
- `{time}` などの変数名は変更・削除しないでください。表示位置は変更できます。
- HTMLやアイコンは画面側で管理します。短い訳文にHTMLを含めないでください。
- アクセシビリティ用のラベルも共通UI辞書に含まれます。

## 詳細説明の翻訳

Markdownを固定IDのブロックに分けています。

```md
<!-- i18n:overview -->
## Overview

Write the translated description here.

<!-- i18n:installation -->
## Setup

1. Download the tool.
```

- `<!-- i18n:... -->` は単独行に置き、IDを翻訳・変更しないでください。
- 同じ文書内でIDを重複させないでください。空のブロックは使えません。
- 日本語の並び順を基準に英語のブロックを表示します。ブロック内の文章・段落は自然な訳になるよう変更できます。
- 新しい内容を追加した場合は、意味のわかる新しいIDを付け、日英の両方に追加してください。
- リンク先、画像のパス、配布ファイル名、実行コマンドは維持してください。リンクや画像の参照先の相違は検査します。
- Mermaidのラベルも翻訳します。ノードIDやリンク先は維持してください。
- 画像は共通です。ツール本体の画面が日本語であれば、画像も日本語のままです。

翻訳の下書きを確認するには、次のコマンドを使えます。日本語のID付き内容を標準出力へ表示し、ファイルは変更しません。

```bash
node scripts/check-translations.mjs --template kco-relay
node scripts/check-translations.mjs --template ui
```

## 原文を変更したとき

1. 日本語を更新します。
2. `npm run check:translations` を実行します。`source needs review` の後に再確認が必要なIDが表示されます。
3. 対応する英訳を修正するか、変更の影響がないことを確認します。
4. 確認済みの範囲について、次のコマンドで確認記録のパッチを表示します。

```bash
# 共通UI
node scripts/check-translations.mjs --review-patch ui

# 1ツールの名前・概要・詳細説明
node scripts/check-translations.mjs --review-patch kco-relay
```

このコマンドは `translation.meta.json` の差分を出力するだけです。対象範囲の英訳をすべて確認してから、表示されたパッチを適用してください。ファイル編集には `apply_patch` を使います。確認記録だけを先に更新すると、翻訳の未更新を検出できなくなります。

5. `npm run check:translations` と `npm run build` を実行し、プレビューで日英の表示を確認します。

英訳だけを修正した場合、原文の確認記録を更新する必要はありません。確認記録はUTF-8の原文から計算するSHA-256で、改行コードの違いは無視します。

## プレビューと言語選択

```bash
npm run dev
```

- 一覧の英語表示: `http://localhost:5173/?lang=en`
- 詳細の英語表示: `http://localhost:5173/tool.html?tool=kco-relay&lang=en`
- 日本語表示: `?lang=ja`

言語はURLの指定、保存した選択、ブラウザの優先言語の順に判定します。対応する言語がなければ日本語です。ヘッダーでの選択を保存し、URLにも反映します。ブラウザの保存機能が使えなくてもURLで切り替えられます。

言語切り替えはページを再読み込みします。現在のツール、クエリ、フラグメントは維持します。一覧・詳細・本文・Mermaid図のツール間リンクにも言語を引き継ぎます。

選択言語の詳細説明を通信障害などで取得できない場合は、日本語の説明へ戻し、案内を表示します。その本文には `lang="ja"` を設定します。通常の公開では翻訳の不足や未確認の原文変更をビルド時にエラーにします。

## 言語を追加するとき

サイトの対応言語は `src/i18n/languages.mjs` の `LANGUAGES` にまとめています。各言語のコード・自言語名・日時表示のロケールをここで登録します。

登録された言語から、一覧・詳細共通のヘッダーの選択肢、言語判定、辞書の読み込み、日時表示、詳細説明ファイル名、翻訳チェックの対象言語が決まります。これらを個別に修正する必要はありません。

新しい言語の公開時は、共通UIの `<言語コード>.json`、各ツールの `locales/<言語コード>.json` と `detail.<言語コード>.md` をそろえ、登録後に確認記録を更新してください。日本語原文の言語は同じファイルの `SOURCE_LOCALE` で指定しています。

現時点の実装と公開対象は日本語・英語です。
